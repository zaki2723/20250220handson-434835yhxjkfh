# 2. Amazon EC2 の作成


## 2-a. Amazon EC2の作成

**目標**-WordPress がインストールされた EC2 インスタンスを パブリックサブネット-1a 上に 1つ 作成します。

***

### 2-1. EC2 インスタンスの作成
インスタンスを起動をクリック

***

### 2-2. 作成する EC2 インスタンスの名前を入力
名前とタグに任意の名前を入力(今回はhandson0309ec2と入力)

<img width="800" src="img/2-1.png">

***

### 2-3. 使用する AMI を選択
今回は、EC2 インスタンスの OS は Amazon Linux 2023 を使用

<img width="800" src="img/2-2.png">

***

### 2-4. インスタンスタイプの選択  
Amazon EC2 では、異なるユースケースに合わせて最適化されたさまざまなインスタンスタイプが用意されている  
今回はデフォルトの **t2.micro** インスタンスを選択。

<img width="800" src="img/2-3.png">

***

### 2-5. キーペアの設定
「キーペア名」に キーペアなしで続行 を選択
(AWS Systems Manager Session Manager で EC2 インスタンスに接続を行う為、SSHキーペア(SSHでのログイン)は使用しない)  

<img width="800" src="img/2-4.png">

***

### 2-6. ネットワーク設定  
EC2 インスタンスを、パブリックサブネット-1a 上に作成するため、ネットワーク設定とファイアーウォール(セキュリティグループ)の設定を行います。  

1. 「ネットワーク設定」の右にある 編集 をクリック
2. 「VPC」で 今回作成したハンズオン用 VPC を選択 (今回は: handson-0309)
3. 「サブネット」で パブリックサブネット-1a を選択
4. 「パブリック IP の自動割り当て」で 有効化 を選択  

<img width="800" src="img/2-5.png">

5. 「ファイアウォール (セキュリティグループ)」で セキュリティグループを作成する を選択
6. 「セキュリティグループ名」「説明」ともに web-ユーザ名 (例: web-user1) と入力
7. 「インバウンドセキュリティグループのルール」で、すでに表示されている セキュリティグループルール 1 を変更していきます
8. 「タイプ」を ssh から HTTP に変更
9. 「ソースタイプ」を 任意の場所 から 自分のIP に変更します。そして、「ソース」に 自分のグローバルIPが表示されていることを確認 (図で マスキングされている部分)

<img width="800" src="img/2-5-2.png">

10. 「高度なネットワーク設定」は、なにも変更せず（デフォルトのまま）します。次に、ストレージ設定を行います。

***

### 2-7. ストレージ設定
デフォルト のまま（ 8 GiB / gp3 ルートボリューム）にします  

<img width="800" src="img/2-6.png">

***

### 2-8. 高度な設定（ IAM ロールの設定とWordPressの自動インストール ）
- EC2 インスタンスの初回起動時に自動で後述のスクリプトを実行し、WordPress の自動インストールを行います。

#### 2-8-1. 「高度な詳細」を展開
**高度な詳細** をクリックして展開して、一番下にある **「ユーザーデータ」** までスクロールする。

<img width="800" src="img/2-10.png">

#### 2-8-2. WordPress インストールスクリプトの設定  
<u>以下のコード</u>をコピーして貼り付ける

```
#!/bin/bash

dnf update -y
dnf install -y httpd wget php-fpm php-mysqli php-json php php-devel mariadb105

wget http://ja.wordpress.org/latest-ja.tar.gz -P /tmp/
tar zxvf /tmp/latest-ja.tar.gz -C /tmp
cp -r /tmp/wordpress/* /var/www/html/
chown apache:apache -R /var/www/html

systemctl enable httpd.service
systemctl start httpd.service 
```

<br>

**「ユーザーデータは既に base64 エンコードされています」のチェックは外したままにします**

# 3-b. DB サブネットグループの作成
これから行うこと

<img width="100%" src="img/4-6.png">

セキュリティグループ設定
